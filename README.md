# CutForge(工作代号)

**Agent 优先的开源 AI 视频编辑器 —— 社区版。**

用对话驱动剪辑:你描述想法,AI 直接在真实的多轨时间线上完成添加、切割、
排列、字幕,每一步都可撤销、可继续手工调整。CutForge 不是"生成一段不可
修改的视频",而是维护一个真正可编辑的视频工程。

> 命名说明:"CutForge" 是开发代号,正式发布名待定。

## 状态

早期开发中(MVP)。当前能力:

- 多轨时间线(视频/音频),片段拖拽、裁剪、分割、删除
- Canvas 预览播放器(视频/图片/音频合成)
- 本地素材导入(视频/音频/图片)
- 撤销 / 重做
- AI 对话剪辑(自带 API Key:OpenAI / GLM / DeepSeek 等 OpenAI 兼容接口)

## 路线图

- [x] 时间线核心:不可变工程文档 + 命令层 + 撤销栈

## 开发

```bash
npm install
npm run dev      # http://localhost:5300
npm test         # 核心逻辑单元测试
npm run lint
npm run build
```

要求 Node.js 20+(建议 24)。AI 功能在应用内"设置"里填入任一
OpenAI 兼容接口的 Base URL 与 API Key(存储在浏览器本地,不经过任何第三方)。

## 双版本模式

本项目(社区版)以 AGPL-3.0-or-later 开源。面向团队/企业的云端能力
(同步、协作、渲染、订阅)作为独立的闭源服务提供,通过公开 API 与社区版
交互;社区版不依赖闭源服务即可完整使用本地剪辑功能。
